## 1. Overview & Objective
The objective of this assignment is to understand and implement dataset versioning in MLOps workflows using **Data Version Control (DVC)** coupled with Git. Datasets evolve continuously as new samples are recorded or cleaned. Storing large datasets directly in Git leads to severe repository bloat and performance degradation. DVC solves this by decoupling raw data storage from metadata tracking, creating lightweight `.dvc` pointer files that are versioned in Git.

## 3. Step-by-Step Execution Guide

### Step 1: Initialize Git and DVC
```bash
# Initialize Git repository
git init

# Initialize DVC repository
python -m dvc init
git commit -m "Initialize DVC"
```

### Step 2: Create Dataset Version 1
```bash
# Create initial data file
cat << EOF > A1/data/student.csv
RollNo,Name,Marks
1,Amit,80
2,Rahul,72
3,Priya,91
4,Sneha,88
EOF

# Track dataset using DVC
python -m dvc add A1/data/student.csv

# Commit metadata to Git
git add A1/data/student.csv.dvc A1/data/.gitignore
git commit -m "Initialize DVC and track student.csv v1"
```

### Step 3: Modify to Dataset Version 2
```bash
# Append record
echo "5,Neha,77" >> A1/data/student.csv

# Track updated dataset in DVC
python -m dvc add A1/data/student.csv
git add A1/data/student.csv.dvc
git commit -m "A1: Dataset Version 2 with 5 student records"
```

### Step 4: Verify Rollback and Restoration
```bash
# Roll back to Version 1
git checkout HEAD~1 A1/data/student.csv.dvc
python -m dvc checkout
# Verify: student.csv now contains 4 records

# Return to Version 2
git checkout HEAD A1/data/student.csv.dvc
python -m dvc checkout
# Verify: student.csv now contains 5 records
```

### Step 5: Configure Remote Storage and Test Disaster Recovery
```bash
# Setup local remote
python -m dvc remote add -d localstorage A1/storage/dvc_remote
git add .dvc/config
git commit -m "Configure DVC local remote storage"

# Push datasets to remote
python -m dvc push

# Disaster recovery test: delete local data and pull
rm A1/data/student.csv
python -m dvc pull
# Verified: student.csv is restored bit-for-bit from remote storage
```

## 4. Key DVC Commands Summary
| Command | Purpose |
|---|---|
| `python -m dvc init` | Initializes DVC in the repository |
| `python -m dvc add <file>` | Computes MD5 hash and creates pointer `.dvc` file |
| `python -m dvc push` | Uploads tracked data files to remote storage |
| `python -m dvc pull` | Downloads tracked data files from remote storage |
| `python -m dvc checkout` | Synchronizes working directory data with current `.dvc` pointers |
| `python -m dvc remote add` | Adds and configures remote storage location |
